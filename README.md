# AROHA - SIH 2026

AI-Powered Cognitive & Memory Companion.

## Running Locally

1. Terminal 1 (Backend): `cd aroha-backend && npm install && npm start`
2. Terminal 2 (Frontend): `cd aroha-frontend && npm install && npm run dev`
3. Open `http://localhost:5173`
