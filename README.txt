# AROHA Localhost Quickstart

This package contains the fully configured backend and frontend to run AROHA Phase 1 immediately on your machine.

## Step 1: Start the Backend (Terminal 1)
1. Open a terminal and navigate into the `aroha-backend` folder.
2. Run: `npm install`
3. Run: `npm start`
(Leave this terminal open)

## Step 2: Start the Frontend (Terminal 2)
1. Open a new terminal and navigate into the `aroha-frontend` folder.
2. Run: `npm install`
3. Run: `npm run dev`

Open the link provided in the terminal (usually http://localhost:5173).
